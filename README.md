# Check inspection labels before building a risk queue

An inspection team needs to know where its records are incomplete before using them to rank facilities. This study will measure recorded evaluation and stack-test result coverage in a fixed EPA ICIS-Air snapshot. A missing national record will stay missing; it will not become a passing inspection or a safe facility.

**Current state: protocol committed before bulk retrieval.** No coverage result, risk model, improved detection or operational benefit is established. [The fixed protocol](PROTOCOL.md) defines the current-facility cohort, calendar windows, result categories and independent checks. The full national source will remain private; only minimal factual projections with hashed source keys may be published after checks.

The study is a descriptive label and coverage audit. It will not rank named facilities for enforcement or fit a violation-risk model without a defensible target and selection process. Separate formal-publication projects, including Azure optimization, are excluded.
